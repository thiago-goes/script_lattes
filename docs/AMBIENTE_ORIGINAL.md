# Ambiente original de coleta

O coletor por navegador foi desenvolvido em um ambiente Docker/Chromium gerenciado, com proxy e certificados próprios dessa infraestrutura. Os caminhos `/workspace` no coletor original pertencem a esse ambiente. O código permanece disponível para adaptação. Não acompanha credenciais, certificados, HTMLs brutos ou dados de pessoas reais.

Para executar localmente, use o README e o guia DESENVOLVIMENTO.md. A demonstração não consulta o CNPq. Para novas fontes autorizadas, prepare um cadastro local e importe HTMLs completos, preservando a rastreabilidade.
